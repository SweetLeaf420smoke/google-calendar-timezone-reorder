# Публикация расширения в Chrome Web Store

## Шаги для публикации:

### 1. Подготовка файлов

Убедитесь, что у вас есть:
- ✅ manifest.json
- ✅ Все JS файлы (content.js, popup.js)
- ✅ HTML файлы (popup.html)
- ✅ Иконки (icon16.png, icon48.png, icon128.png)
- ✅ Скриншоты (нужно создать)

### 2. Создание ZIP архива

```bash
# В папке проекта выполните:
zip -r google-calendar-timezone-reorder.zip . -x "*.git*" "*.md" "PUBLISH.md" "README.md"
```

### 3. Регистрация в Chrome Web Store

1. Перейдите на https://chrome.google.com/webstore/devconsole
2. Войдите в аккаунт Google
3. Заплатите единоразовый взнос $5 (если еще не платили)
4. Нажмите "Новый элемент" (New Item)
5. Загрузите ZIP файл

### 4. Заполнение информации о расширении

**Название:** Google Calendar Timezone Reorder

**Краткое описание (132 символа):**
```
Изменяет порядок отображения часовых поясов в Google Calendar без изменения основного часового пояса событий.
```

**Подробное описание:**
```
Google Calendar Timezone Reorder позволяет изменить порядок отображения часовых поясов в боковой панели календаря, не меняя основной часовой пояс для событий.

Особенности:
• Перетаскивание часовых поясов для изменения порядка отображения
• Сохранение настроек между сессиями
• Автоматическое применение при загрузке страницы
• Не влияет на основной часовой пояс событий

Идеально для:
• Команд, работающих в разных часовых поясах
• Людей, часто путешествующих
• Международных проектов

Как использовать:
1. Откройте Google Calendar с настроенными часовыми поясами
2. Нажмите на иконку расширения
3. Перетащите часовые пояса в нужном порядке (первый в списке будет справа)
4. Нажмите "Сохранить" и обновите страницу календаря
```

**Категория:** Productivity (Продуктивность)

**Язык:** Русский, English

**Скриншоты:**
- Минимум 1, максимум 5
- Размер: 1280x800 или 640x400
- Формат: PNG или JPG

**Иконка магазина:**
- Размер: 128x128 пикселей
- Формат: PNG
- Используйте icon128.png

**Маленькая рекламная картинка (необязательно):**
- Размер: 440x280 пикселей

### 5. Конфиденциальность

**Политика конфиденциальности:**
Расширение не собирает и не передает никакие личные данные. Все настройки хранятся локально в браузере через chrome.storage.sync.

**Права доступа:**
- storage - для сохранения настроек
- scripting - для работы со страницей календаря
- Доступ к calendar.google.com - для работы с календарем

### 6. Публикация

1. Выберите видимость:
   - **Ограниченный доступ** - только по ссылке (для тестирования)
   - **Публичный** - доступен всем в магазине

2. Нажмите "Опубликовать"

3. Ожидайте модерации (обычно 1-3 дня)

### 7. После публикации

- Расширение появится в Chrome Web Store
- Вы получите ссылку для распространения
- Можно отслеживать статистику установок

## Важные замечания:

⚠️ **Перед публикацией:**
- Проверьте работу расширения на разных версиях Chrome
- Убедитесь, что нет ошибок в консоли
- Протестируйте на реальных данных

⚠️ **Требования Chrome Web Store:**
- Расширение должно работать без ошибок
- Должна быть политика конфиденциальности (если собираете данные)
- Описание должно быть точным
- Скриншоты должны показывать реальную функциональность
