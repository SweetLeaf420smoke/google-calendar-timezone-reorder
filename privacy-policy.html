Политика конфиденциальности

Google Calendar Timezone Reorder

Последнее обновление: 2024

Сбор данных

Расширение Google Calendar Timezone Reorder не собирает никакие личные данные пользователей.

Хранение данных

Все настройки (порядок часовых поясов) хранятся локально в браузере пользователя через API chrome.storage.sync. Эти данные:

  • Не передаются на внешние серверы
  • Не доступны разработчику
  • Синхронизируются только между устройствами пользователя через аккаунт Chrome

Права доступа

Расширение запрашивает следующие права:

  • storage - для сохранения настроек пользователя
  • scripting - для работы со страницей Google Calendar
  • Доступ к calendar.google.com - для работы с календарем

Сторонние сервисы

Расширение не использует сторонние сервисы и не передает данные третьим лицам.

Изменения в политике

Если политика конфиденциальности изменится, пользователи будут уведомлены через обновление расширения.

Контакты

По вопросам конфиденциальности обращайтесь через страницу расширения в Chrome Web Store.
